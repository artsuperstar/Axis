# Workout Rotations v2 review

Actual `WorkoutRotationsScreen` / `WorkoutRotationEditorScreen`, bundled with existing RN Web tooling and the real Lora/Manrope assets. Build with `node node_modules/tsx/dist/cli.mjs scripts/preview-workout-rotations.ts`; open `dist/rotations-review/index.html`.

Fixtures are generated by the real SQLite/migrations/Fitness/rotation APIs in the existing preview runner. The default fixture has the saved Weight Training rotation active, with Chest, Triceps, Shoulders next, matching the supplied current-state example. `?multiple`, `?long`, `?many`, `?empty`, `?editor`, `?editor&edit`, `?editor&edit&locked` select review states. The inactive state is real; Paused is never fabricated. Empty removes the fixture's saved rotations from the browser projection. Menus and form state run actual components; browser mutation callbacks record/update review state rather than writing to native SQLite.

Captures cover dark/light 390pt, multiple rotations, empty, 320/430pt, 320pt simulated doubled text (top and scrolled card), anchored menu, New/Edit, locked Edit and large-text Edit. Native safe area/status bars are excluded. Doubled text is a browser approximation, not an iPhone Dynamic Type result. `review.json` records overflow/runtime checks and actual mounted card count for the 103-rotation browser fixture. No exact pixel-coordinate tests are used in the automated suite.

Physical Expo Go verification is still needed for iOS/Android scrolling and keyboard behavior, Dynamic Type, VoiceOver/TalkBack, native confirmations, menu placement/dismissal/focus restoration and resume/refresh with an unsaved draft.
