## Positive constraints for every correction

- Work History is **already v2**. Migrate its default Client History header/shared fallback only; preserve SectionList, Jobs/Receipts counts, settled classification, payment allocations and paging.
- Preserve Home's five approved photographs, both textures, row-anchored expansion and direct Fitness/Journal navigation.
- Preserve native Router hierarchy and five tabs; no custom global tab replacement, route consolidation or bottom-inset normalization.
- Preserve source semantics: scheduled task date, historical recurrence/schedule version, paid vs expected, Earned vs Received, skipped vs unpaid, status labels and actual contextual actions.
- Keep Reduced Motion, optional performance inputs, keyboard and focus ownership; strengthen native acceptance before changing high-risk shared headers.

## Suggested skill sequence after approval

Use `$impeccable harden` for confirmed control-boundary/focus problems (VU-04/05), `$impeccable typeset` for named type roles (VU-10), `$impeccable adapt` for reproduced native scaling issues (VU-14), and `$impeccable audit` after each migration unit. Finish implementation review with `$impeccable polish`. These are future options, not commands executed in Phase 1.
